# NovaKrishi — Direct Agricultural Marketplace

> **Tagline:** "From Farm to Market, Fair & Direct."  
> **Supporting Tagline:** "Empowering Farmers. Simplifying Markets."

NovaKrishi connects farmers, FPOs, consumers and bulk buyers through a transparent digital marketplace powered by AI-driven insights and smart logistics.

## Key Features
- **Direct Marketplace:** Direct farmer-to-consumer & bulk buyer trading without middleman markups.
- **AI Demand Forecasting:** Predictive crop demand & price forecasting engines.
- **Smart Logistics:** Vehicle routing optimization (VRP) & live GPS delivery tracking.
- **Fair Pricing:** Live Mandi benchmark pricing transparency.
- **Secure Escrow Payments:** Protected payment milestone workflows.

## Technology Stack
- **Frontend:** React 19, TypeScript, Tailwind CSS v4, Vite, Lucide Icons
- **Backend:** Node.js, Express, TypeScript, JWT, MongoDB / In-memory data store
